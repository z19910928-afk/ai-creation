## 本轮可用流程

1. 在主页面右侧常驻聊天中讨论灵感、人物或情节，也可引用当前章或选区。
2. 不附带整章时，仍提供有限的作品概览、规划和相关设定；不会因此暗中发送章节正文。界面显示上一轮实际参考范围。
3. 满意的方案可预览为灵感草稿，作者确认后保存到设定库。新记录标记为“灵感”和尚未发生的作者计划，重复确认不会重复保存，也不直接修改正文或正式记忆。
4. 需要写作时，沿用聊天中的任务确认、手动启动、候选比较与作者采纳流程。“查看正文候选”定位到对应任务的候选。
5. 生成期间修改正文、设定或规划，完整聊天回答仍会保留，提示“回复依据是发送时的资料；资料已更新，本轮操作建议已取消。”本轮全部操作建议取消，后续历史和备份恢复保留旧参考标记。

聊天完成时仍核验完整请求、会话归属、作品、分支、章节和来源绑定。仅当前资料变化可以保留文字；请求篡改继续失败。发送前、确认执行和正文采纳的校验没有放宽。
