# 模型配置流程核验记录

日期：2026-10-18。

本轮目标是让作者先填服务地址和密钥，自动得到可选模型，再测试、保存和分配用途。模型接入选项必须真正影响模型发现、连接测试、写作任务和写作总管，不能只改变界面。

## 参考项目与取舍

参考 NovelForge 源码，固定版本为 `a485814411546b3980df0a1696a0fb6a043d56ce`。本次仅阅读源码，没有运行上游服务或使用真实密钥。

- `backend/app/services/llm_config_service.py`：集中处理服务地址、接口协议、模型列表路径、请求路径和客户端标识。模型发现和模型工厂共用这些配置。
- `backend/app/api/endpoints/llm_configs.py`：模型列表与连接测试分开，查询列表不等于测试成功。
- `backend/app/services/ai/core/chat_model_factory.py`：临时测试配置和保存后的配置使用同一个模型工厂。
- `backend/app/services/ai/core/llm_capability_probe.py`：思考内容也可能占用输出额度，过小的连接测试额度会把可用模型误判为空回复，上游为此使用 1024 的测试额度。

墨屿保留现有更严格的边界：必须完整结束；回传模型名称明确不一致时不能通过；测试凭证绑定实际设置；密钥只在本机私密文件保存；不自动重试可能收费的生成请求。

上游的自定义请求路径属于给模型库追加的基础路径。本轮墨屿采用更清楚的定义：自定义路径填写的是同一服务上的最终完整路径。

## 实现合同

### 页面流程

参考上游 `LLMConfigManager.vue` 与 `LLMConfigForm.vue` 的列表管理和新增/编辑对话框结构，独立实现本项目的界面。上游通过按钮获取模型；本项目按照作者要求保留自动获取，并额外提供刷新和手动输入。上游保存不强制连接测试，本项目继续要求先测后存。

模型库只展示已保存连接；新增、编辑、添加同服务模型均在按需打开的窗口完成。显示名称可选，测试成功后可仅保存或同时设为默认。更多写作参数、用途分工和传输兼容选项默认折叠，输入错误会展开相应区域。

写作总管提供默认、模型库、独立连接三种方式。独立连接先测试草稿，成功取得限时凭证后才覆盖已保存设置；失败保留原来可用的连接。模型库模式使用总管自身默认参数，不带入主写作或旧独立连接的协议专用参数，保存前按实际聊天格式校验。

### 接入选项

支持 `openai_compatible`、`openai`、`deepseek`、`qwen`、`siliconflow`、`ollama`，默认 `openai_compatible`。这些选项使用当前已经支持的兼容接口。接口协议继续由 Chat Completions / Responses 明确选择，不借品牌名称假定已经支持其他原生接口。

三个可选字段默认为空：

| 字段 | 作者理解的含义 | 空值行为 |
| --- | --- | --- |
| `custom_request_path` | 写作请求发送到的路径 | 使用当前协议的标准路径 |
| `models_path` | 获取模型清单的路径 | 使用标准 `/models` |
| `user_agent` | 服务识别此客户端时使用的名称 | 实际发送 `Moyu/1` |

基础地址保留作者明确填写的版本路径，不猜测或强行追加 `/v1`。复制进来的 `/chat/completions`、`/responses`、`/models` 末尾会统一去除，再确定实际请求地址。

自定义路径必须以单个 `/` 开头，在同一主机和端口上使用。拒绝外部完整地址、双斜线开头、查询参数、片段、路径跳转和换行，避免把已保存密钥发送给其他服务。客户端名称必须是适合发送为请求头的短文字。

### 测试、保存和默认用途

1. 模型列表查询只读，不保存草稿、不消耗写作生成次数。
2. 测试发出一次短请求，使用 1024 的输出额度；可接受“连接正常”外围的简短标点和空白。
3. 未完整结束、模型名称不一致、长篇无关回复仍不能生成保存凭证。
4. 保存仅接受有效测试凭证；修改地址、协议、路径或客户端名称必须重新测试。
5. `use_as_default: true` 允许保存验证连接并同时设为默认；任何一步失败都回到保存前的状态，不能留下半保存连接或消耗凭证。
6. 不选设为默认时，不改变作者已有默认模型或用途分配。

### 复用已经保存在本机的密钥

同一服务提供多个模型时，`source_connection_id` 可以明确选择一个已保存连接作为密钥来源，查询列表并另存一个新模型。新建与编辑分开，不能同时传入 `id` 和 `source_connection_id`。

复用必须限定当前作品与同一服务地址，不能跨主机、端口或基础路径发送原密钥。公开响应、作品数据库、写作队列和备份不得出现密钥正文。

### 历史任务与备份

保存的验证签名覆盖全部接入选项。升级前只有三项兼容设置的连接和测试凭证，在新字段全为默认值时仍然有效；新增字段有变化时不能沿用旧签名。

排队任务保存自己的完整接入设置和请求记录，包括最终请求地址与实际客户端名称。执行或重试时校验这些设置。旧任务未记录客户端名称时，只能按原来的默认 `Moyu/1` 解释。

作品备份保留非秘密接入设置，清除密钥引用、测试凭证、验证状态及默认用途。恢复后要重新填密钥并测试。

## 验证方式

专项测试文件：`tests/model_transport_settings_fixtures.py`。

测试只使用临时作品数据库、临时私密目录和两个本机 HTTP 模拟服务，不访问用户作品，不调用真实模型，不产生接口费用。模拟服务实际接收请求，核验最终路径、客户端名称、协议正文和授权边界。

主要覆盖：

- 接入选项校验、复制完整接口地址、根地址和自定义最终路径。
- 模型列表与实际 Chat / Responses 请求使用同一接入配置。
- 连接测试的标点容忍、输出额度、截断与模型不一致拒绝。
- 保存密钥复用、新建不同模型、跨作品和跨地址拒绝。
- 测试凭证绑定、自定义字段篡改拒绝、旧签名与旧凭证升级兼容。
- 保存时同时设默认及失败原子回滚。
- 写作队列冻结、实际请求记录和旧默认客户端名称兼容。
- 备份恢复保留路径并清除密钥、验证和用途。
