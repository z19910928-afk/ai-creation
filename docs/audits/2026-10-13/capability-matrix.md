# 全能力对照矩阵

日期与版本见[固定来源](sources.md)。此矩阵覆盖创作、资料、编辑、记忆、审稿、模型、任务、书架、恢复、导入出版与运行交付。

“已有”只说存在入口或后台；带缺陷者不能视为验收通过。E表示源码入口/处理/保存/消费已追踪，R必须按专项标出的组件或页面范围理解，S只表示结构，U为未验证或未发现完整闭环。上游效果总体U；不做功能数量排名。

每个项目的逐维原始核查在[七份专项](projects/README.md)中。下表采用最相关的参考项目，避免把所有项目都当成在每个方向领先。

## 如何使用矩阵

当前优势是作者确认、证据和追加版本的设计基础，不是已经证明比所有上游更安全。上游优势是某些更完整的作者流程，不是所有功能都成熟。两边都必须按同一证据等级接受验收。

具体改动顺序见[路线与验收](roadmap.md)，当前运行失败见[缺陷清单](findings.md)。未核准的范围不会因为加入菜单就从U变成完成。
