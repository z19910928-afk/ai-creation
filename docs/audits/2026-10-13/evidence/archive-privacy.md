# 公开审计归档与隐私范围

日期：2026-10-13。公开仓库保留审查结论、固定提交身份、失败记录和复验范围，同时脱敏本机用户名、工作区绝对路径、macOS 的 `/var/folders/...` 临时运行目录，以及 GitHub 元数据中的非必要个人邮箱。

公开副本与原字节不同。逐文件的原件指纹、公开副本指纹和脱敏字段类别记在 [archive-redactions.json](archive-redactions.json)。未脱敏原件保存在 Git 忽略的 `artifacts/private-audit-originals/2026-10-13/`，私有文件按 `0600` 权限保存。元数据内的提交 SHA 不变；含个人邮箱的签名载荷经过脱敏后，将公开 `verification` 标为不可直接复验，并单独保留原验证状态。要核对原字节或签名，应使用私有原件或从固定提交重新取得官方元数据，不能对公开副本套用原指纹。

追加脱敏时继续保留最早的私有原件及其指纹，并合并脱敏类别，不以当前公开副本覆盖原件。公开说明后续编辑造成的指纹变化也会单独登记；原件丢失或与已登记指纹不符时，工具停止处理，需先恢复原件。

文学样本、冻结方案、冻结请求、请求账本和它们的指纹不在本次路径脱敏范围内，不重写正文、已发生请求或失败结果。`blind-key-private.json` 是匿名候选的方法映射，已由 Git 忽略，不进入公开仓库，也不交给评审。

报告里的本机源码路径改为相对仓库根目录；上游取证缓存改为 `./.audit-cache/2026-10-13/`，固定墨屿基线缓存改为 `./.audit-cache/moyu-baseline/`，系统临时运行目录改为 `./.audit-cache/runtime-artifacts/`（无法保留可移植后缀的路径会标记为 `<private-macos-temp>`）。这些位置是复跑时的约定目录，缓存和私有原件均不提交。公开探针仍需要按[固定来源](../sources.md)取得原提交；它们不是独立包含七个项目的运行包。当前修复回归以 `tests/` 为准，基线探针只证明原报告的历史触发条件。

维护者可先运行 `node scripts/publish_audit_archive.cjs` 查看待脱敏清单和待更新的公开副本指纹；预览不会写文件。核对后用 `--apply` 机械生成公开副本、保留私有原件并更新记录。该工具只处理审计文档、源码元数据和历史探针的路径，不读取模型密钥，不执行收费调用。
