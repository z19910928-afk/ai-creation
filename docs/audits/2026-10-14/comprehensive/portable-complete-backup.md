## 已实现合同

服务器只在当前配置的数据目录工作。上传文件保留在服务器内存中，预览不修改真实数据库；数据库是保存作品、历史和任务的本地 SQLite 文件。ZIP 不需要原作品、原备份登记或原凭据目录，也不按上传内容解压至电脑路径。

| 请求入口 | 接受资料 | 已实现行为 |
| --- | --- | --- |
| `POST /api/backups/import/preview` | `filename`、`data_base64`、可选 `preview_id` | 检查原始 ZIP、清单、结构、作品内引用及内容指纹，返回标题、时间、真实数量、兼容性、有效期及警告；同token同文件同scope同数据库返回同份预览，不延长原有效期，不返回整包资料 |
| `POST /api/backups/import/apply` | `preview_id`、`archive_sha256`、`title`、`confirm:true` | 使用服务器保存的原 ZIP，重新校验后建立独立作品；首次成功201，同资料重试200并返回同一副本，已保存后改资料409 |
| `POST /api/backups/import/cancel` | `preview_id` | 释放未保存预览，不写作品；预览尚未到达或仍在校验时也记录取消，拒绝同token的迟到预览；正在保存时409，避免取消与提交竞争 |
| `POST /api/backups/import/status` | 与 apply 相同的四字段 | 只读查询：已保存返回 `saved:true,result`；未保存返回 `saved:false,preview_available`；不能借查询再建作品 |

限制为 ZIP 压缩体积32 MiB、HTTP请求48 MiB、展开总量256000000字节；最多同时保留两份预览、原始字节合计64 MiB、有效期30分钟。作品名最多200个完整 Unicode 字符，包含 emoji 时不按字节或半个字符截断。

电脑页面在上传前生成 `restore_preview_<32位小写十六进制>` token，刷新或关闭时可以用它取消尚未回应的预览。服务器先占校验槽，并发同token等待同一校验；改ZIP、文件名、作品、分支或数据库409。取消记录限512条、在当前服务进程内保留30分钟，校验完成前后都重新检查槽是否已关闭；迟到请求不能重新占槽。旧客户端仅传两个文件字段仍兼容。

首次提交将全部恢复行和 `project.portable_restored` 事件放入同一事务。持久回执键为 `portable_restore_<preview_id>`，记录原目标作品/分支、请求指纹及副本身份。重复确认、并发确认、回复丢失和服务重启都读取这份已提交回执。结果查询等待正在保存的同一预览，并用立即事务读取后回滚，不抢先返回“未保存”。保存阶段异常回滚后保留可重试预览；保存成功后释放内存包。

## 包与字段边界

SHA256 是内容指纹，用来发现字节或文字变化，不能证明外部包来自可信作者。ZIP原始字节的 `archive_sha256` 与包内原始 `project.json` 的 `project_sha256` 分开核对。

## 草稿与删章资料保护

首次读取作品失败时，页面里的占位内容不是该作品的真实草稿。只有成功读取真实作品、载入合法本机草稿或实际编辑过内容后，页面才写草稿缓存；未改占位内容直接保存不会激活缓存。主缓存缺失或损坏时，读取同一作品的合法 `:base` 副本，不能借用另一作品的副本。只有残留未保存标记、没有合法稿件时，不制造占位稿冲突。切换作品重置这项状态，旧作品迟到的读取回应也不能污染当前作品。

本轮审查先发现“只剩合法 `:base` 时返回占位稿”和“初次读取失败后未改内容直接保存会缓存占位稿”两个反例，再完成修复。该轮 `app.js` 的实际读取、缓存、保存和回填函数在隔离内存中通过10项控制；这是轻量执行证据，不能充当真实浏览器测试。真实 Chrome 另已覆盖读取失败后重新打开已保存副本、保留另一页实际编辑的离线草稿和迟到请求。

整份作品保存时遗漏章节，以及 `DELETE /api/chapters/<id>`，都会先登记删章，再撤回这章全部旧版本原句所支撑的记忆与正式事实：原句和记忆变为失效，正式断言退回候选，不能继续进入新请求的提示材料。人物状态历史行及原正文版本保留；人物状态依赖的断言已失效时，从本次提示材料中排除。其他章的有效记忆、事实和未关联该断言的作者人物状态保持。

删章修前的记录显示，页面虽标出资料过期，底层记忆仍可能是 `accepted`、正式断言仍是 `canon`；后续预览会拒绝变化后的资料。修后两种删章入口都通过真实本机 HTTP 验证，预览正常生成且不含已删事实。故意在失效操作中途让数据库触发器拒绝更新时，两种入口均返回409，全库内容回到请求前。未删章的历史已确认记忆即使显示旧名称、引用旧版本，无变化保存仍逐行保真。
