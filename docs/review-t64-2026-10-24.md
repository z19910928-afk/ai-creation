## 五、F1 复现与 requiredFix

**场景 A（含换行 key，实测泄漏）**

```python
key = "sk-t65-line1\nline2-abcdefgh"
headers = {"Authorization": f"Bearer {key}"}
runner 返回 (7, "", "E"*100 + key)   # stderr 只回显裸 key，没有 "Bearer " 前缀
# 实测 error.detail 尾部："…EEEEEsk-t65-line1\n***"
```

**场景 B（<8 字符凭据跨 200 边界，实测泄漏）**

```python
key = "sk-abcd"                     # 7 字符
runner 返回 (7, "", "G"*196 + key)  # 截断落在 key 中间
# 实测 error.detail 尾部："…GGGGsk-a"（provider 层 _redact 匹配不到被截断的 key）
```

根因在 `backend/moyu_extract.py:580-595`：

```python
for value in headers.values():
    if len(value) >= 8:
        secrets.add(value)              # 整条 "Bearer <key>"
    parts = value.split()
    if parts and len(parts[-1]) >= 8:
        secrets.add(parts[-1])          # 只到「末个空白分隔 token」
```

即：凭据被登记的形态只有「整条 header 值」和「末个 token」，而且两者都被 ≥8 过滤。
当 stderr 里的文本是「裸 key」且 key 内含空白（`split()` 把它切碎）或 key 短于 8 字符时，
完整凭据串不在候选集里，`_redact_secrets` 无从匹配；跨边界截断后连
provider 层 `_redact(error.detail, self.api_key)`（`:514`）也无法匹配半截。

**requiredFix**（最小改法，既覆盖 A/B，又不误伤短通用值）：

1. `_header_secrets()` 对 `Authorization`（header 名大小写不敏感）**无条件**登记两个候选：
   整条值、以及 `value.split(None, 1)[1]`（scheme 之后的剩余值），**不受 ≥8 长度过滤**——
   Authorization 的值按定义就是凭据，不需要靠长度猜。
2. 其余 header 维持现行为（≥8 才登记），避免把 `POST` 之类短词替换成 `***`。
3. 新增 fixture：`key = "sk-t65-line1\nline2-abcdefgh"`，runner 返回
   `(7, "", "E"*100 + key)`，断言 `key.split()[0] not in error.detail`；
   再加一条 7 字符 key 跨 200 边界的用例，断言 `key[:4] not in error.detail`。

## 六、覆盖边界（明示，不得写成「真实模型已通过」）

1. **本机没有 `MOYU_EXTRACT_*` 凭据**：`--mode openai` 真实调用仍 exit 2，本报告**未**验收
   真实外部模型；t63 报告里 captain 的本地假服务冒烟（1 章 6774 字、deterministic
   `identical=True`）只证明「CLI → 默认 curl → 解析」闭环，且它的 `engine.sha256` 是
   t62 时代的 `d4a06035…`，**不是**本报告绑定的 `4457a0e7…`——本轮没有新的真实冒烟证据。
2. **Windows**：`--config -`（配置走 stdin）+ 请求体走临时文件 + `shlex` 式引号在 curl 的
   Windows 构建上语义相同，属静态推断，未实跑。
3. **本轮未做并发/压力**：只验证单进程单请求路径。
4. **短凭据（<8）**：transport 层不脱敏（有意避免误伤短通用值），provider 层仅在完整凭据
   出现时兜底；跨边界截断时仍可能残留前缀——已并入 F1 的修复建议，不另立 finding。
5. **取证限制**：被测两文件 untracked，无法 diff 到 t63 时点（§零），「只改授权写域」
   只能由 t64 自述 + 仓库状态一致来支撑，不是我独立证明的结论。
