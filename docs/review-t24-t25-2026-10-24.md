## 二、实现核验

### 2.1 分组键确实带属性槽位

`backend/moyu_consistency.py:356-363`（t24 改动处）：

```python
groups: dict[tuple[str, str, str], list[sqlite3.Row]] = {}
for row in rows:
    value, broken = parsed[row["id"]]
    slot = "" if broken else _attribute_slot(value)
    groups.setdefault((row["subject_entity_id"], row["predicate"], slot), []).append(row)
```

- 键是三元组 `(row["subject_entity_id"], row["predicate"], slot)`，`slot` 来自 `_attribute_slot(value)`（`backend/moyu_consistency.py:250-261`：`dict.attribute` 为字符串才取 `strip()`，缺失/非字符串/整体非 dict → `""`）。
- 非对象断言（标量、字符串、数组）与坏 JSON 都落 `""` 槽；坏 JSON 另有单条 medium 报告（`:340-355`），并在配对循环 `:372-373` 跳过，不会与空槽断言比较。
- 探针 A1/A2 用同一实体 10 条不同 `attribute` 的 `has_story_fact` 复现：**0 条 fact finding / 100.0 分 / A**。
