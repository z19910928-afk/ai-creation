# 墨屿 v0.1.2

本次集中修复模型配置与写作总管接入，让添加模型、测试、保存、开始写作形成完整流程。

## 主要更新

- 模型配置改为列表管理，新增或编辑时打开弹窗；高级参数和用途设置默认收起。
- 填写服务地址和密钥后自动获取多个模型，支持搜索选择、手动填写和重新获取。
- 测试通过后才能保存；“保存并用于写作”可以同时启用默认模型，显示名称留空时自动命名。
- 增加服务商预设、自定义请求路径、模型列表路径和请求标识，显示最终请求地址；兼容 Chat 与 Responses。
- 同一服务可复用本机保存的密钥添加其他模型，密钥不会回填到页面；更换服务商或服务地址时须重新填写密钥。
- 修复复制完整模型列表地址后的重复路径拼接，以及带简短标点的正常回复被判失败；连接测试输出额度调整为 1024。
- 写作总管可沿用默认模型、选择模型库中的已验证模型，或配置独立连接；独立配置先测试再保存，失败保留原配置。
- 修复总管使用 Responses 库模型时混入主模型的 Chat 专用参数，以及发送后中断丢失派发记录的问题。
- 改善折叠参数错误提示、取消操作、慢请求返回、作品切换，以及直接打开网页文件时的提示。

## 安装与数据

| 电脑 | 安装包 |
| --- | --- |
| Mac，Apple 芯片 | `Moyu-0.1.2-mac-arm64.dmg` |
| Mac，Intel 芯片 | `Moyu-0.1.2-mac-x64.dmg` |
| Windows，64 位 | `Moyu-0.1.2-win-x64.exe` |

每个平台另有备用 ZIP 与 `SHA256SUMS-*.txt` 校验文件。Mac 需要 macOS 15 或更新版本。当前没有发行者证书，Mac 使用本机临时签名，尚未进行 Apple 公证。

作品和密钥保存在本机。升级应保留原有数据目录；作品备份不包含密钥，恢复后需要重新填写并测试。使用远程模型时，本次任务所需正文和资料会发送到所选服务，连接测试与生成可能产生该服务的费用。

## 验证范围

本轮验证使用隔离临时作品和本机模拟模型服务，没有调用真实远程模型，也没有进行文学质量评测。工程通过不代表所有第三方服务已经验证，也不代表文学效果达到“第一梯队”。

配置行为与专项检查见[模型配置核验记录](../audits/model-configuration-redesign-20261018.md)。安装包的实际构建与发布状态以[桌面安装说明](../desktop-packaging.md)中的对应版本记录为准。
