# 墨屿 v0.1.1

这次更新完善模型接入，让新安装的软件也能使用最新模型配置流程。

- 填写服务地址和密钥后自动获取模型清单，支持搜索、键盘选择、鼠标选择及手动填写；同一服务的多个模型可以分别加入模型库。
- 主模型和写作总管都可选择 Chat 或 Responses 接入方式，实际聊天、续写与各项用途使用已保存的接入方式。
- 模型先测试、再保存，之后才能在用途设置中选择。获取清单不会自动生成、测试或保存。
- 更换服务地址时不沿用原密钥；切换作品或连接后取消旧请求，避免旧列表污染新设置。
- 更新页面资源版本，减少升级后继续显示旧设置页面的问题。
- 扩展安装包内的模型发现和 Responses 验收，保留正文、聊天草稿、导出、备份与重启检查。

## 下载与安装

Mac Apple 芯片选择 `mac-arm64.dmg`，Intel 芯片选择 `mac-x64.dmg`；Mac 需要 macOS 15 或更新版本。Windows 64 位选择 `win-x64.exe`。ZIP 为备用压缩包，`SHA256SUMS-*.txt` 可用于核对下载文件。

升级程序会继续使用原桌面数据目录。建议升级前在“备份中心”导出完整作品备份。软件不附带模型密钥，已有源码版作品需要导出完整备份后在桌面版恢复。

当前安装包没有发行者证书，Mac 未经过 Apple 公证，系统可能显示开发者或发布者提示。安装与数据说明见仓库 `docs/desktop-packaging.md`。

验证记录、各平台运行结果和下载版本以仓库桌面安装说明为准；工程检查与文学质量评测分别记录。
