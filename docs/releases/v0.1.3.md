# 墨屿 v0.1.3

本次更新集中完善常驻写作总管：讨论灵感、确认任务、查看候选和中断恢复都留在主窗口中，并补齐模型清单获取的错误提示与恢复。

## 主要更新

- 兼容聊天服务返回的完整普通文字、JSON 围栏及多行回答，不再将可阅读的完整回复误判为格式失败。纯文字只用于讨论，不推测或执行操作；截断、取消和损坏回复仍不能转为成功。
- 灵感讨论可以预览并确认保存到设定库，记录为作者计划，不会自动写进正文或正式记忆。生成期间资料发生变化时保留完整回答，但取消已过期的操作建议。
- 任务卡显示实际步骤和当前等待的作者操作，可折叠查看大纲、场景及正文候选；阶段切换和刷新任务显示时保留展开状态与预览滚动位置。
- 如果请求没有送达本机服务，任务卡提供“核对并重试原步骤”。只有作者明确点击才会重发；刷新、轮询、切换聊天和服务恢复都不会自动生成。
- 重试前重新核对作品、分支、任务身份、原检查点和规划候选。状态已变化、规划候选变化、来源过期或离开原聊天时停止，不猜测、不自动采纳。
- 同一检查点的并发恢复只提交一次；采用完整规划不会额外触发模型生成。
- 明确指定的历史规划找不到时继续保留原选中状态。只有作者明确选择“查看当前最新规划”才会打开另一份规划。
- 模型清单区分证书、连接、解析和超时错误，清单被测试操作暂停后能恢复获取；有界重连只针对尚未收到响应的清单读取，不自动重发生成请求。
- 整理前后端目录，精简仓库首页；保留原来的启动入口、页面地址和作品数据位置。

## 安装与数据

| 电脑 | 安装包 |
| --- | --- |
| Mac，Apple 芯片 | `Moyu-0.1.3-mac-arm64.dmg` |
| Mac，Intel 芯片 | `Moyu-0.1.3-mac-x64.dmg` |
| Windows，64 位 | `Moyu-0.1.3-win-x64.exe` |

每个平台另提供备用 ZIP 和 SHA256 校验文件，用于核对下载文件是否完整。三平台原生构建和安装检查全部通过后才自动发布，不替换旧版 `v0.1.2` 的标签或文件。

作品、原稿、模型连接和密钥仍保存在本机；安装程序不携带开发电脑的数据或密钥。升级前建议导出完整作品备份，升级时保留原桌面数据目录。旧版本中缺少原候选校验信息的“结果待核对”记录仍只能回看，不猜测身份后自动重试。

Mac 需要 macOS 15 或更新版本。当前没有发行者证书，macOS 尚未进行 Apple 公证。安装、数据目录、备份和密钥设置说明见[桌面安装说明](../desktop-packaging.md)。

## 验证范围

本次源码改动通过隔离数据库、本机模拟服务、浏览器回归和真实桌面开发版检查；未调用真实远程模型。只有三种目标平台的安装包构建、包内服务、真实窗口及安装后检查全部通过，才算本版桌面包验证完成。

专项范围见[任务中断恢复](../audits/agent-task-recovery-20261021.md)、[任务卡与成果预览](../audits/agent-chat-task-cards-20261021.md)、[聊天与灵感修复](../audits/agent-chat-inspiration-repair-20261019.md)和[模型清单恢复](../audits/model-inventory-reliability-20261018.md)。这些记录中的历史真实连接检查与本轮不调用远程模型的工程验收分开，不累加成新的文学评测。

工程验证不等于文学质量评测，不代表所有模型服务都已实测，也不能证明文学效果达到“第一梯队”。
