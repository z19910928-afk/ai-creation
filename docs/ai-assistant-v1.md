# AI 创作助手 v1

墨屿现在提供一个可选的 AI 创作助手，但它保持“作者主导”：模型只生成候选，正文只有在作者点击采纳后才会改变。

产品工作流从首页“开始创作”向导开始，先建立一句话故事设定、主角、阻力和第一章，再进入章节编辑。每章结束后，作者可以归档本章并自动准备下一章；AI 候选会随章节切换清空，避免把上一章的建议误用于新章节。

## 任务

- 续写当前场景
- 生成场景卡
- 规划故事走向
- 发散三个走向
- 润色当前章节
- 总结当前章节
- 连续性检查

## 上下文策略

请求由服务端组装，包含作品简介、当前章节末尾工作集、最近三章片段、设定卡、情节看板和已确认记忆。故事文本包在 `<manuscript>` 数据区中，系统提示明确声明其中的文字不是指令。完整作品不会因为一次 AI 请求被无差别发送。

当前版本没有 tokenizer、embedding 或向量检索；它是“有界工作集 + 人工确认记忆”的安全起点。下一阶段应增加章节/场景分块、FTS5、事实来源 span、token 预算、生成 run 审计和候选 patch，而不是直接把整本书塞入上下文。

## 配置

```bash
MOYU_AI_BASE_URL=https://api.example.com/v1 \
MOYU_AI_MODEL=your-model \
MOYU_AI_API_KEY=your-key \
python3 server.py
```

没有配置时，离线助手会提供可用的场景卡、写作检查和大纲模板，不会联网。远程响应最多读取 2 MB，超出、空响应、连接失败或异常格式都会拒绝采纳。
